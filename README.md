# ces-manifests (archived)

This repository is no longer maintained. Use
[clyso/ces-helm-charts](https://github.com/clyso/ces-helm-charts) instead.
Its charts pin tested versions of Rook and ceph-csi and are published at
`https://charts.ces.clyso.com`.

To install CES with Rook, see
[Install CES with Rook](https://docs.clyso.com/docs/kb/rook/install-ces-with-rook/).
To move an existing installation onto the new charts, see
[Moving existing upstream releases](https://github.com/clyso/ces-helm-charts/blob/main/charts/README.md#moving-existing-upstream-releases-to-these-charts).

The values files in `rook/helm-charts/` are kept so that existing links to
them keep working. They target the upstream Rook 1.19 charts and are not
updated.
